# RCA Vertex Global — Fresh Website

A modern, responsive static website for RCA Vertex Global Private Limited.

## Free deployment recommendation

For this commercial company website, use **Netlify Free** rather than GitHub Pages. Netlify's current Free plan supports commercial projects and provides free deployment, custom domains with SSL, and a global CDN.

### Netlify quick deployment

1. Create/sign in to a Netlify account.
2. Choose **Add new project** → **Import an existing project**.
3. Connect your GitHub account.
4. Select the repository containing these files.
5. For a plain HTML/CSS/JS site, leave the build command empty.
6. Publish directory: `/` (root).
7. Deploy.

Netlify will give you a free `*.netlify.app` address.

## Before going public

- Replace `info@rcavertexglobal.com` if you use a different business email.
- Replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml` after you have a domain.
- If you already own a domain such as `rcavertexglobal.com`, connect it later in Netlify.
- Replace the text favicon/logo with your official logo if desired.
